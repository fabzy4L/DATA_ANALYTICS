# Gene Expression — Nicotine Study (qPCR Analysis)

R and Python analysis of gene expression changes associated with nicotine use across human and rat cohorts (normal diet and high-fat diet).

> **Context:** Gene expression data from qPCR instruments was used to investigate 
> how nicotine exposure affects gene regulation in human and rat cohorts across 
> normal and high-fat diet conditions. Analysis includes interaction models, 
> fold-change normalization, and visualization via R and Power BI.

---

## Tools & Stack
- **R / R Markdown** — statistical modeling, interaction models, figure generation
- **Python** — normality testing on CT values  
- **Power BI** — fold-change dashboard
- **qPCR instrument data** — raw CT value exports

# Python Data Analytics Workspace

A consolidated repository of data science, bioinformatics, and automation projects. This workspace is organized by domain to facilitate project management and discoverability.

## 📂 Project Structure

### [BIOINFORMATICS/](./BIOINFORMATICS)
Projects focused on life sciences, molecular biology, and genomic data.
*   **Drug Discovery**: Bioactivity data analysis and binding affinity studies.
*   **qPCR**: Tools for transforming and analyzing quantitative PCR data.
*   **Receptor Design**: Molecular modeling and receptor analysis.
*   **Sequence Analysis**: Genomic and protein sequence identification and manipulation.

### [MACHINE_LEARNING/](./MACHINE_LEARNING)
General-purpose machine learning models and deep learning experiments.
*   Convolutional Neural Networks (CNNs).
*   Deep Learning basics.
*   Classification models (Iris dataset).
*   Integration with R via Reticulate.

### [DATA_ACQUISITION/](./DATA_ACQUISITION)
Pipelines for gathering and processing external data.
*   **Web Scraping**: Selenium and BeautifulSoup scripts for data extraction.
*   **Audio Processing**: Transcription and audio extraction tools.

### [ANALYTICS_LAB/](./ANALYTICS_LAB)
Learning resources and foundational data analysis.
*   **Fundamentals**: Core Pandas and data manipulation tutorials.
*   **Education**: Coursework, quizzes, and book-related scripts.
*   **Templates**: Reusable processing templates for new projects.

### [ENGINEERING_AND_SPECIAL_PROJECTS/](./ENGINEERING_AND_SPECIAL_PROJECTS)
Specialized applications and niche domain analysis.
*   **Engineering**: Finite Element Analysis (FEA) and CAD automation with Python.
*   **Sports Analysis**: UFC fight data and technique analysis.
*   **Social Data**: Exploratory analysis of social datasets.

### [UTILITIES/](./UTILITIES)
General utility scripts and shared helper functions.

---

## 🛠️ Setup and Requirements
Most projects in this repository require:
*   Python 3.x
*   Pandas / NumPy
*   Matplotlib / Seaborn
*   Jupyter Notebook / Lab

*Specific requirements (e.g., Selenium, BioPython, RDKit) are noted within their respective project directories.*

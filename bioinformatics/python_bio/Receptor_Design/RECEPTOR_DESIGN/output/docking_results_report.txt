INTERPRETATION

The mutation introduces a gamma-methyl group (Thr vs Ala) at position 348.
The very small computed delta G (+0.027 kcal/mol) suggests minimal steric
impact at this level of analysis. This is consistent with position 348 being
relatively peripheral to the core S1 binding pocket (centroid-to-res348 CA
distance ~6 Angstrom).

The prior "Methyl Clash" hypothesis (estimated 175-fold Ki increase based on
analogy with S438T) is NOT supported by this direct docking result. However:

  1. The analogy used (S438T) refers to a DIFFERENT residue that is more
     central to the S1 binding pocket.
  2. Position 348 in 5I6Z is ALA (not SER as in the biological WT). The
     true comparison point for S348T should start from a SER-348 structure.
  3. These charges are simplified approximations; Gasteiger charges via
     openbabel would improve accuracy.
  4. Higher exhaustiveness (e.g., 32) and multiple seeds are recommended
     before drawing conclusions.
